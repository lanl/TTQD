How to cite
===========

A general citation to the TTQD package is appreciated.
The Bibtex entry is::

  @Misc{ttqd,
    title = {TBA},
    author = {Yu Zhang; xxx},
    url = {https://github.com/lanl/ttqd},
  }

For specific features used in the calculation, a citation recommendation is listed at the end of the output.
